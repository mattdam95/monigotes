# monigotes

Catálogo de ejercicios en español con muñecos 3D animados ([Posecode](https://posecode.org)), pensado para planes de entrenamiento dentro de artifacts de Claude.

- `ejercicios/`: un archivo `.posecode` por ejercicio.
- `src/catalogo.ts`: validación con `posecode-parser`.
